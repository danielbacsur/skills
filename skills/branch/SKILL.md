---
name: branch
description: Use whenever creating, renaming or suggesting a git branch name.
---

Name the branch `<type>/<description>`, using one of `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore` or `revert`, the same type the work's main commit would use. Leave out scopes, issue numbers, usernames and tool or harness prefixes.

Write the description in lowercase kebab-case, a few plain words that say what the branch does. Keep the whole name between 20 and 40 characters, aiming for about 30 and never going past 50. If it doesn't fit, rephrase it instead of cutting words into abbreviations.
